Function reference

Core

Validation, robust statistics, and logging utilities.

core.healpix_cell_sizes Return HEALPix cell sizes for one or more spherical bodies.
core.validate_nside Validate that nside is a power of 2.
core.mad Compute Median Absolute Deviation.
core.robust_std Compute robust standard deviation using MAD * 1.4826.
core.setup_logger Create a logger with the standard healpyxel output format.

Sidecar

HEALPix sidecar generation and PSF-weighted assignment.

sidecar.compute_healpix_ids_from_lonlat Compute HEALPix cell IDs for arrays of lon/lat coordinates in degrees.
sidecar.detect_lonlat_columns Auto-detect longitude and latitude columns from a DataFrame sample.
sidecar.process_partition Process a single dask partition and return DataFrame of assignments.
sidecar.add_psf_weights_to_sidecar Add a weight column to the sidecar DataFrame using PSF functions.
sidecar.normalize_weights_per_cell Normalize weights so that sum of weights per cell is 1.0.
sidecar.build_output_path Build output path for sidecar file based on input and parameters.
sidecar.write_sidecar_metadata Write sidecar processing metadata to a JSON companion file.
sidecar.validate_nside Validate that nside is a positive power of two.
sidecar.get_healpix_cell_geometry Return a shapely Polygon for the given HEALPix cell.
sidecar.get_psf Return a PSF callable for the given type.
sidecar.GaussianPSF 2D Gaussian Point Spread Function centered at (0,0).
sidecar.compute_assignment_weight Compute the assignment weight for a (source geometry, cell geometry) pair.

Candidate Search

HEALPix candidate-cell search backends (ADR-020).

healpix_search.QueryPolygonSearch Convex polygon search via healpy.query_polygon.
healpix_search.QueryDiscSearch Bounding-cap search via healpy.query_disc.
healpix_search.AutoSearch Try backends in declared order, fall back on CandidateSearchUnsupported.
healpix_search.CandidateSearchUnsupported Raised when a backend cannot handle the given geometry.
healpix_search.DEFAULT_SEARCH

Aggregate

Sidecar aggregation and output generation.

aggregate.aggregate_by_sidecar Aggregate observation data by HEALPix cells using a sidecar mapping.
aggregate.collect_sidecar_outputs Scan output_dir for sidecar parquet files matching the input stem.
aggregate.densify_healpix_aggregates Densify aggregated DataFrame to include all HEALPix cells.
aggregate.generate_output_filename Generate output filename that matches the parseable structure of the sidecar.
aggregate.extract_nside_from_filename Extract nside value from sidecar filename using regex.
aggregate.validate_sidecar_metadata Validate sidecar metadata file and check source file match.
aggregate.process_single_sidecar Process a single sidecar file through the full aggregation workflow.

Accumulator

Streaming accumulation with TDigest percentiles.

accumulator.StreamingStats Container for streaming statistics using Welford’s algorithm.
accumulator.CellAccumulator Accumulator for a single HEALPix cell.
accumulator.accumulate_batch Process one batch of data and update the accumulator state.
accumulator.save_state Serialize accumulated state to Parquet with metadata.
accumulator.load_state Load accumulator state, HEALPix metadata, and processing history from parquet.
accumulator.state_to_dataframe Convert accumulated state dict to a DataFrame with explicit healpix_id column.
accumulator.validate_accumulator_sidecar_compatibility Validate that accumulator state is compatible with sidecar file.
accumulator.find_sidecar Attempt to find matching sidecar file for input data.
accumulator.ensure_not_processed Check/add input fingerprint in state metadata for idempotency.

Finalize

Statistics finalization and export.

finalize.finalize_statistics Convert accumulator state to final statistics DataFrame.
finalize.densify_healpix_map Create a complete HEALPix grid by filling empty cells with fill_value.
finalize.export_to_geotiff Export a HEALPix column to GeoTIFF format.
finalize.load_state Load accumulator state, HEALPix metadata, and processing history from parquet.

Metadata

HEALPyxelxMetadata embedding and validation.

metadata.HEALPyxelxMetadata Validated HEALPix grid metadata with embedded parquet I/O.
metadata.FileType Pipeline file type discriminator.
metadata.read_metadata_from_file Unified metadata reader with intelligent fallback strategy.
metadata.save_with_metadata Save DataFrame with embedded HEALPix metadata.
metadata.validate_sidecar Validate sidecar structure and return diagnostic metrics.
metadata.validate_aggregate Validate aggregate DataFrame structure.

CLI

Command-line interface entry points.

cli.sidecar_cli CLI entry point for healpyxel_sidecar.
cli.aggregate_cli CLI entry point for healpyxel_aggregate.
cli.accumulator_cli CLI entry point for healpyxel_accumulator.
cli.finalize_cli CLI entry point for healpyxel_finalize.
cli.to_geoparquet_cli CLI entry point for healpyxel_to_geoparquet.
cli.cache_cli CLI entry point for the healpyxel-cache command.
cli.inspect_cli CLI entry point for healpyxel_inspect.
cli.validate_lon_lat_columns Validate or auto-detect longitude/latitude columns.
