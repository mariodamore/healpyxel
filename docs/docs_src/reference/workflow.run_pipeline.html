Run the 3-phase pipeline (sidecar → aggregate → geoparquet).

Returns a list of dicts, one per executed stage: {"stage": str, "nside": int|None, "status": "ok"|"skip"|"error", "detail": str}.

Skip detection reads .meta.json (sidecar/aggregate) or globs .geo.parquet-family files. Skipped stages are reported with a ⏭.

Parameters

input — input parquet file. Must exist. output_dir — working directory for sidecars and aggregates. nsides — HEALPix resolutions. Default (32, 64, 128). lon_convention — "0_360" or "minus_plus180". Default "minus_plus180". mode — "strict" or "fuzzy". Default "fuzzy". columns — value columns to aggregate. None → auto-discover all float64/double columns. aggregate_columns — always-included columns (appended to auto-discovered set). Use to force HK defaults, e.g. ("TARGET_DISTANCE_median",). aggs — aggregation functions. Choices: mean, median, std, min, max, mad, robust_std. Default ("mean", "median", "std", "robust_std"). filter — pandas query expression for pre-aggregation filtering. densify — fill empty HEALPix cells with NaN. use_duckdb — use DuckDB backend (default True). use_dask — use Dask for parallel aggregation. min_count — minimum observations per cell for valid aggregation. verbose — print equivalent CLI commands before each stage. log — write a self-contained bash script to this file handle. sidecar_kwargs / aggregate_kwargs / geoparquet_kwargs — per-stage overrides. Highest precedence.

Examples

Minimal call:

from pathlib import Path
from healpyxel.workflow import run_pipeline

results = run_pipeline(
    input=Path("test_data/samples/sample_50k.parquet"),
    output_dir=Path("healpix/"),
)

With overrides:

results = run_pipeline(
    input=Path("test_data/samples/sample_50k.parquet"),
    output_dir=Path("healpix/"),
    nsides=(32, 64),
    aggs=("median", "mad"),
    min_count=2,
    verbose=True,
    log=open("pipeline.log", "w"),
)

                    HEALPix nside values (default: 32 64 128).

--densify
--no-duckdb
--use-dask

Run the 3-phase pipeline (sidecar → aggregate → geoparquet).

Returns a list of dicts, one per executed stage:
`{"stage": str, "nside": int|None, "status": "ok"|"skip"|"error", "detail": str}`.

Skip detection reads `.meta.json` (sidecar/aggregate) or globs
`.geo.parquet`-family files. Skipped stages are reported with a `⏭`.


## Parameters

**`input`** — input parquet file. Must exist.
**`output_dir`** — working directory for sidecars and aggregates.
**`nsides`** — HEALPix resolutions. Default `(32, 64, 128)`.
**`lon_convention`** — `"0_360"` or `"minus_plus180"`. Default `"minus_plus180"`.
**`mode`** — `"strict"` or `"fuzzy"`. Default `"fuzzy"`.
**`columns`** — value columns to aggregate. `None` → auto-discover all
  `float64/double` columns.
**`aggregate_columns`** — always-included columns (appended to auto-discovered
  set). Use to force HK defaults, e.g. `("TARGET_DISTANCE_median",)`.
**`aggs`** — aggregation functions. Choices: `mean, median, std, min, max,
  mad, robust_std`. Default `("mean", "median", "std", "robust_std")`.
**`filter`** — pandas query expression for pre-aggregation filtering.
**`densify`** — fill empty HEALPix cells with NaN.
**`use_duckdb`** — use DuckDB backend (default `True`).
**`use_dask`** — use Dask for parallel aggregation.
**`min_count`** — minimum observations per cell for valid aggregation.
**`verbose`** — print equivalent CLI commands before each stage.
**`log`** — write a self-contained bash script to this file handle.
**`sidecar_kwargs` / `aggregate_kwargs` / `geoparquet_kwargs`** — per-stage
  overrides. Highest precedence.


## Examples
