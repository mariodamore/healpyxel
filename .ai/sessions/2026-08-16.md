### Key findings
- `healpy.query_polygon` hard-errors on non-convex input, making it unsuitable as universal mechanism
- `shapely.prepare()` returns `None` in shapely 2.x (prepared geometry stored internally)
- `query_disc` with `max_central_angle + 1° margin` is safe for any polygon shape
- Duplicate consecutive vertices (including closing point) cause "degenerate corner" errors in `query_disc`

### ADR-019 updated
- Status changed from "Proposed" to "Active"
- Two-tier approach (convex `query_polygon` / concave `query_disc`) replaced with single `query_disc` approach
- Implementation details, bug fixes, and test results documented

## Dead Ends
- Tried `healpy.query_polygon` with convexity check — failed for antimeridian polygons that appear convex in planar lon/lat
- Tried `shapely.prepare()` for performance — returns `None` in shapely 2.x
- Tried `query_polygon` with `fact` parameter — still fails on non-convex input

## Decisions Made
- Use `query_disc` exclusively for exhaustive mode (no `query_polygon`)
- Remove convexity check entirely — `query_disc` is always safe
- Direct `intersects()` calls instead of `shapely.prepare()`
- Default `exhaustive=False` preserves backward compatibility
